## Design Context

### Users
- **Primary audience**: Casual home users watching IPTV content
- **Context**: Users interact with this tool to discover working portals, browse channels, and stream content — typically in a relaxed viewing context on desktop or tablet
- **Job to be done**: Quickly find and start watching channels with zero friction; the tool should get out of the way and let users focus on content

### Brand Personality
- **Efficient & Direct**: The interface prioritizes speed and clarity over decorative flourishes
- **Voice**: Action-oriented, minimal text, clear labels — buttons like "START DISCOVERY" and "VERIFIED SERVERS" communicate purpose instantly
- **Emotional tone**: Calm efficiency — the tool should feel like a reliable utility that works without demanding attention

### Aesthetic Direction
- **Theme**: Dark mode only (optimized for viewing in dim/low-light environments)
- **Color palette**: Subdued, muted tones — avoid vibrant or energetic colors in favor of calm, understated hues
  - Background: Deep, near-black bases that recede into the background
  - Accent: Muted, desaturated colors that guide without overwhelming
  - Text: High-contrast but not harsh — comfortable for extended viewing
- **Typography**: Outfit (Google Fonts) — clean, readable, modern sans-serif
- **Visual style**: Functional modernism — rounded corners and subtle depth for affordance, but no decorative glows, gradients, or animations that distract from content
- **Anti-patterns**: Avoid generic minimalism — the interface should have enough visual structure and hierarchy to guide users without feeling sterile

### Design Principles
1. **Content first, always**: The interface recedes; channel logos, names, and video playback are the heroes — UI chrome is secondary scaffolding
2. **Zero friction to playback**: Every interaction should reduce the distance between user intent and watching content; minimize clicks, loading states, and decision points
3. **Accessibility is non-negotiable**: Maintain WCAG AA contrast, keyboard navigation, screen reader support, and reduced motion — casual users include users with diverse abilities
4. **Calm through restraint**: Use color, animation, and visual effects sparingly; the interface should feel peaceful and focused, not exciting or stimulating
5. **Structure without sterility**: Provide clear visual hierarchy and grouping so users can scan and find content quickly, but avoid over-minimalism that makes the interface feel empty or corporate
